Project Statement

Problem Statement

Manual library record management can make it difficult to track book availability, student borrowing, due dates, overdue books and borrowing history accurately.

Scope

The project provides a console-based Java system for maintaining book and student records and managing the complete book circulation process.

Target Users

- College/school library staff
- Librarians
- Students for demonstration purposes

High-Level Features

1. Book management
2. Student management
3. Book issue and return
4. Automatic due-date calculation
5. Automatic overdue fine calculation
6. Borrowing history
7. Library reports

Fine Policy

Each issued book has a 14-day free borrowing period. After the due date, a fine of ₹10 per overdue day is calculated.

Academic Concepts Demonstrated

- Classes and objects
- Encapsulation
- Collections
- Methods and modular design
- Exception handling / input validation
- File handling
- Date and time API
- Basic sorting and searching
- Layered project structure
